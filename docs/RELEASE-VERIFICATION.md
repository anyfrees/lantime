# LanTime 1.0.3 发布校验

- 当前 Windows 11 / .NET Framework 4.x：74 项功能检查、47 项界面检查通过。
- 真实回环 UDP：NTPv3 / NTPv4、来源多数一致、异常来源排除、CIDR 限制、过期状态等检查通过。
- 自动校准 Windows 时间通过注入模拟系统时钟验收，包括多源分歧、权限失败、写入后回读、反向校准、休眠恢复；没有实际改变测试电脑的系统时间。
- MSI：通过 Windows Installer 管理解包，退出码 0；解包后的所有应用文件逐项 SHA256 与源载荷一致；解包后的程序重新通过 74 项功能检查。
- 安装版与便携版共用 AnyCPU / .NET 4.0 应用文件。安装标记只改变配置数据路径及界面启动权限行为。
- 当前执行环境不是管理员，未执行系统注册安装、升级、卸载、快捷方式创建和管理员服务维护的动态验收。MSI 支持相应表项和目录归属校验，但不能视为已完成现场安装认证。
- 未完成 Win7 实机、高 DPI 多屏、SCM 开机和长时间运行验收。
- 安装包未做代码签名。使用前可对照 dist 中生成的 SHA256SUMS.txt。

## 本地构建

运行 `build.ps1` 编译应用；运行 `package.ps1` 运行检查并构建便携 ZIP 和 MSI。生成物、用户数据和本地工具不会被提交到 Git。
