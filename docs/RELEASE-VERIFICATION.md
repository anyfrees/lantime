# LanTime 1.0.6 发布校验

- 当前 Windows 11 / .NET Framework 4.x：80 项功能回归、47 项界面检查、35 项 MSI 原生引擎及维护条件检查。
- 已通过 VNC 在用户 Win7 SP1 上阅读 1.0.5 的详细安装日志：StopOwnedService returned actual error code 183，紧接着 MSI Error 1722，最终安装结果 1603。服务指向桌面便携版，目标是 Program Files 安装目录。不是 .NET 缺失或应用无法在 Win7 启动；用户确认便携版正常。
- 1.0.6 针对已证实的失败路径修复：不同目录的后台服务返回成功并保持原样。回归覆盖该桌面路径、有服务 / 无服务、同目录停止与卸载、无效路径不得操作任何服务。
- 新版启动时明确提示原服务位置和切换方法，防止从新版 ProgramData 目录错误读取旧版便携服务的状态和配置。不会自动迁移、停止或删除旧服务。
- 带日志安装包检测 UTF-16LE（含无 BOM）、UTF-8 和系统代码页，并保留动作前后文；1.0.5 的 findstr 无法读取 Win7 UTF-16 日志，已修正。
- 1.0.3 缺少 Signature 等标准表导致错误 2228，该问题已在 1.0.4 修复。
- 1.0.6 已在当前 Windows 11 上实际从 1.0.5 升级、修复和卸载，退出码均为 0；最终安装另行记录。不能据此推断已完成 Win7 安装验收。
- 真实回环 UDP、多源共识、异常源排除、NTPv3/v4、CIDR、过期状态、后台服务类生命周期通过功能检查。
- Windows 系统校时使用模拟系统时钟验证；测试没有实际改变系统时间、修改防火墙或开机启动。
- Win7 SP1 已实机核验：Program Files (x86) 安装目录和 installed.mode 正确，文件属性为 1.0.6.0；安装版界面运行正常。桌面旧 settings.json 已保留并复制到 ProgramData\LanTime；用户完成服务切换后，界面显示 1.0.6、后台服务模式、UDP 0.0.0.0:123、4/4 来源同步和本机校准成功。
- 切换后已从另一台局域网电脑实际查询 Win7 的 UDP 123，两次有效 NTP 采样成功，Stratum 3，最低往返约 1.2 ms。网络往返耗时不代表绝对授时精度。
- 尚未完成 Win7 重启启动、长期运行、32 位 Win7 和高 DPI 多屏验收；当前验证仅代表这台 Win7 SP1 电脑。安装包未代码签名。
- 安装日志保存在本地 dist/verification，不上传源码仓库。
